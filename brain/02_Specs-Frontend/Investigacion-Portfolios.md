## Hipótesis del brief

| Hipótesis | Veredicto |
| --- | --- |
| Mono + sans limpia | Confirmada e incompleta: sans + serif de acento + mono de meta |
| Oscuro + borde 1 px | Sigue en producto; en personales gana papel / monocromo claro |
| Bento grids | Sustituida por laboratorios / craft logs y documentos editoriales |

## Tres tendencias

1. **Monocromo silencioso** — columna estrecha, poca imagen, 2–3 tallas, tres voces tipográficas. Riesgo: README con dominio; antídoto: copy con opinión y un detalle memorable.
2. **Prueba ejecutable** — craft logs, demos en navegador, ensayos con control. Fuerte para Data/ML. Riesgo: demo trivial.
3. **Documento de producto** — tabla densa, RFC/postmortem, métricas con fecha. Riesgo: genérico si hay bento o datos falsos.

Referencias clave: emilkowal.ski, paco.me, rauno.me/craft, brianlovin.com, jakecuth.com, ciechanow.ski, wattenberger.com, ajeenckya5.github.io, linear.app.

## Dirección recomendada

Base **P1 · Cuaderno de laboratorio** (estructura, voz, tipografía) + **uno o dos ensayos P3 · Explicable** como casos estrella. **P2 · Consola** solo si el objetivo principal son roles de producto/infra.
